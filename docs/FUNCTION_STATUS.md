# DepthFlow 功能现状清单

更新时间：2026-09-15

本清单是项目首页、公共导航与实际工作流的共同依据。页面文案不得脱离这里单独维护。

## 统一外壳与共享能力

- 已取消独立多人页面与跳转横幅。各衣装智换模式和按秒改写的人物区直接“＋ 添加人物”，每人可上传 / 从角色库选择形象、预览、独立提供服装；最多 4 人，所有图片合计最多 9 张。
- 双人默认男红女白；同性或无法判断时首次同框左红右白。三、四人使用红白黄蓝；在原母版生成步骤按添加人数分色，切镜和交叉走位保持身份。已有母版不自动付费重做。
- 人物增删、服装或其他参考调整后，页面自动显示完整的多人母版与成片提示词；预览与提交共用后台拼接函数，保留用户填写的补充要求，按秒改写按原片帧率显示实际区间。预览只在本地拼接文字，不调用外部模型。
- 新增人物及服装追加在原有场景、物品和其他参考之后，@ 素材实际参与提交；移除素材标记失效引用，其他人物引用随编号调整。绑定与服装在原项目存档中恢复。
- 无人物服装参考流程继续直接引用原片；按秒改写有参考流程使用完整打码视频并一次生成成片，不增加母版、裁剪或衔接步骤。
- 动作迁移及真实 / 虚拟长视频保留原有的逐人添加、上传与绑定；长视频按跨镜身份分色，合法颜色不被白模检查误判。模型效果仍需预览确认。

- 首页按“局部替换 / 长视频重绘 / 动作迁移”展示四个独立项目。
- 项目页统一使用左侧步骤导航、右侧当前步骤内容；项目不需要的步骤由各自注册表隐藏。
- 灰色按钮下方显示不可用原因，点击时弹出缺失条件。
- 付费动作显示模型、分辨率与预计调用次数。
- API 与任务错误统一归类为：网络、余额/额度、审核、参数、素材、系统。
- 长视频分镜支持原片、白膜、成片切换对比。

## 四个独立项目

| 能力组 | 项目 | 当前主要路径 | 隔离原则 |
|---|---|---|---|
| 局部替换 | 衣装智换 | 选择人物/场景/服装/随心换/动态场景更换人物 → 打码 → 白膜 → 素材 → 成片 | 五种模式统一入口 |
| 长视频重绘 | 虚拟人物复刻重绘 | 拆镜 → 打码/表演 → 白膜 → 虚拟角色与场景 → 逐镜成片 | 只面向虚拟人物流程 |
| 长视频重绘 | 真实人物复刻重绘 | 拆镜 → 打码/表演 → 白膜 → 火山角色库 Active Asset → 逐镜或整段成片 | 真人任务、素材、结果与虚拟版隔离 |
| 动作迁移 | 人物动作迁移 | 原片打码 → 动作白膜 → 场景和多人物 / 首尾帧参考 → 成片 | 独立页面、草稿与任务；新人物上传入库、审核通过自动选用，图片预览及 @图片 选择 |

人物动作迁移的原片超过 15 秒时使用前 15 秒；也可直接导入 2–15 秒白膜。白膜使用 Seedance 2.0 / 480p，成片使用 Seedance 2.5 / 480p 或 720p。多人物模式固定 @图片1 为场景，@图片2 起为 1–8 位角色库 Active 人物；首尾画面模式中 @图片1 为必填首帧、@图片2 为可选尾帧，@视频1 始终为动作白膜。首尾画面按参考图片与提示词引导，不保证首尾帧逐像素一致。两种模式均支持草稿保存、历史项目、独立成片预览下载与只读恢复已提交任务；重复请求不会新建付费任务。

人物动作迁移的白膜和成片均通过 TOS 提交参考视频。上传前生成保留帧数与时长的压缩副本，并验证完整下载及文件校验值；存储桶可由 `MOTION_TRANSFER_TOS_BUCKET` 单独指定，不改变其他项目的上传通道。

## 已废弃说明

- 真实人物项目不再把“眼部遮挡图 + Seedream 素描身份图”作为主要身份路径。
- 单人视频复刻与多人视频复刻不再作为产品入口；真实人物复刻重绘可同时处理单人和多人完整复刻，虚拟人物由虚拟人物复刻重绘处理。旧页面与任务文件仅为历史兼容保留。
- 当前真实人物身份路径是：用户确认授权 → 上传火山角色库 → 审核成为 Active Asset → 绑定分镜人物槽位。
- 旧任务中的遮眼图或素描图只作为历史结果保留，不应出现在首页的当前流程说明中。

## 架构边界

- `project_registry.js` 只管理名称、分类、步骤和公共付费提示。
- 四个当前项目继续使用各自的页面脚本、提示词和 API；公共层不得改写内部生成逻辑。
- 公共层可以共享上传预览、错误归类、禁用原因、媒体对比、导航和存档界面能力。

### 衣装智换：动态场景更换人物

入口：/projects/wardrobe#dynamic。上传原片（超过 15 秒按段完整保留，例如 29 秒分为 15 + 14 秒），自动检测并打码视频中出现的全部人脸，不再要求主角框选、描述或定位点；原片可直接复用并免费重新打码。衣装智换打码阈值默认 0.55，可在 0.30–0.90 之间调整；数值越低检测越灵敏，漏码可尝试 0.45，误码较多则调高。任务保存实际阈值，修改后需重新打码并预览，仍不保证自动检测没有遗漏。白模阶段根据叙事主体和人物动作识别主要人物，只有主要人物转换为白模，打码不作为主角识别标记。

预览确认打码后，单独提交 Seedance 2.0 / 480p 白模任务，只替换指定主角；保留动态背景、其他人物、道具和原片文字包装，不提取静态场景图。白模预览确认后，从共享角色库选择 Active 人物（也可上传新图并审核），上传服装图，再使用 Seedance 2.5 生成成片。实际绑定固定为 @视频1＝主角白模、@图片1＝人物 Asset、@图片2＝服装图；可点击标签或输入 @ 插入补充要求。两次视频生成分别确认费用，网络重试复用提交标识。模型生成后的背景与人物保持效果仍需人工预览确认。

### 动态物品、动态背景与按秒改写（2026-09-14）

- 衣装智换新增“动态物品替换”（`/projects/wardrobe#dynamic_object`）：分为两条独立流程。有人物、服装参考时，原片全部人脸打码 → 生成或上传仅主角为白模的视频 → 绑定原片人物 Asset 和服装图，再用提示词替换物品。没有人物、服装参考时，原片视频入库，通过审核后直接以 Video Asset 引用原片进行物品替换，不打码、不生成白模。两条流程均可上传物品参考图；勾选特殊物品时必须附图。
- “动态背景替换”（`/projects/wardrobe#dynamic_scene`）分为两条流程：无原片人物、服装参考时，上传原片至角色库或按素材组选择已有 Active 视频，预览后直接引用原片，用提示词换背景，场景图可选；有参考时，原片全部人脸打码（阈值可调）→ 主要人物白模、背景纯绿 → 人物、服装及场景图还原成片，也可上传已有 2–15 秒绿底白模。@视频1 与图片编号按实际素材绑定；两条流程及物品替换各自保存进度，旧场景空间白模不会误用于绿底白模流程。素材库预览、入库去重及配额提示复用物品替换能力。绿底无法保留全部原场景深度线索，复杂运镜、前景遮挡和落脚关系仍需预览检查。
- 动态物品的人物参考流程：`@视频1`＝主角白模、`@图片1`＝原片人物、`@图片2`＝服装、可选 `@图片3`＝物品图；直接原片流程：`@视频1`＝原片视频 Asset、可选 `@图片1`＝物品图。页面标签与实际提交顺序一致，拒绝未绑定的 @ 引用。两条流程分别恢复存档，旧版物品白模任务不能误用为主角白模。动态场景仍使用 `@视频1`＝场景白模、`@图片1`＝场景图。视频入库保留提交回执，重复请求不重复入库；白模和成片分别确认费用。
- 当前“按秒改写视频”已移除衔接准备和边界确认步骤：选角色库完整原片，或原片打码并绑定人物服装，设置秒数要求后直接生成。多个区间合并为 1 次完整视频生成，原片与完整打码视频均需 2–15 秒；不提取边界图、不裁剪、不拼接。其他参考图片仍可上传和 @ 引用。未指定部分通过提示词要求尽量保留，实际画面、声音和时长以模型结果为准，需预览确认。恢复完整任务只查询并下载原输出，不重复生成或裁剪。
- 旧版“按秒改写视频”（`/projects/wardrobe-continuation`）：从完整原片设置 1–12 个互不重叠的改写区间（每段最多 15 秒），每段独立填写要求。支持开头、中间、结尾及多个分散片段；原片可超过 15 秒。秒数按原片帧率对齐，每段提取本段及附近视频、开始和结束衔接画面，并真实绑定 @ 引用。两秒等短区间按当前生成接口的最小时长生成后裁取前两秒，不拉伸动作；最终按原位置替换，保留其余画面、原声、帧数和总时长。片段顺序生成，确认框显示任务数量；模型衔接效果需预览。
- 按秒改写支持两种素材流程：无人物服装参考时，原片入库或按素材组选择已有 Active 视频，预览后直接引用 `@视频1`，仅用提示词改写（角色库原片需 2–15 秒）；有参考时，完整原片全部人脸打码（阈值可调、可重新打码），`@视频1` 使用本段打码视频，`@图片1` 为上传入库或已选角色，`@图片2` 为服装图，无需白模。每段边界图用于本地预览，新流程不将原片人脸截图送入生成。人物服装参考变更会阻止复用上一批次片段。
- 改写工作台的生成按钮前新增“其他参考图片（可选）”：最多 7 张 JPG/PNG/WEBP，支持分次添加、预览、单独移除与历史恢复。按实际提交顺序绑定图片；无人物参考从 @图片1 开始，有人物服装参考从 @图片3 开始，旧任务随衔接图数量顺延。移除图片会更新后续编号，并将已移除图片的提示词引用标为无效；补充图变化后不会误复用旧片段。不上传时保持原流程。
- 旧版区间改写保留批次及逐段提交记录，响应中断不会重复提交；可恢复已提交片段和拼接。部分失败时，相同要求及设置的已完成片段直接复用，只生成剩余段。旧版后半段任务的原片、结果与恢复入口仍可读取。
- 验证覆盖目标与素材绑定、参数校验、预览/费用门槛、重复提交、任务恢复，以及合成测试视频的前缀逐帧保留、音轨切换和最终时长。未自动运行付费模型，真实生成质量以用户预览为准。

- 动态物品原片库按“素材组 → 组内视频 → 播放预览并使用”选择；新原片名称与上传入口收纳到折叠区。入库前按 SHA-256 核对已有视频，相同内容复用 Active Asset；共享配额满明确提示，不再误报提交结果未知。

### 衣装智换：时长与对白（2026-09-15）

原片上传打码流程支持长片按最多 15 秒拆段，在原页面选择分段逐段制作，全部成片完成后自动合成，可免费重试合成。原始完整文件保留，旧任务中已经截取的前 15 秒不会自动恢复后续内容，需要重新上传完整原片。不足 5 秒的生成参考在末尾补纯黑静音，动作不变速；生成后去掉补时部分。直接引用角色库视频与按秒改写仍沿用各自的素材长度检查。

白模参考不再静音，按原片声音保留对白与抽象下颌节奏；字幕清理只去文字。白模输出重新接入原片音轨，最终替换成片默认保留原片声音，并要求新人物按对白生成口型。多人对白按身份及颜色绑定。旧静音白模在生成成片前自动补音；页面也提供“恢复原片声音（免费）”修复已保存的白模和成片，原文件保留。补音不改变已有闭嘴画面，修正口型需要重新生成并人工预览；未进行付费模型质量验证。
