# 需求：衣装智换客户版插件

创建日期：2026-09-06

## 产品目标

向客户交付一个插件压缩包，由 Codex 或 WorkBuddy 引导安装、配置和使用。CZMIYOU 账号、产品 ID 4 和时间卡只控制插件使用资格；客户自行提供模型供应商 API Key，生成费用由供应商直接收取。

本合同按用户最新确认更新，替代先前中央代收费目标。用户随后授权“改造”，0.2.0 BYOK 代码和本地技术验证已完成；真实账号、供应商、宿主和用户成片验收仍待进行。0.1.0-preview ZIP 保留为旧架构，勿作为新交付。

## 用户、场景和结果

- 用户：购买衣装智换服务的客户，不是假定具备开发环境的内部开发者。
- 场景：选择视频和参考素材，说明换人物、服装、场景或长视频重绘目标；检查中间结果；确认后生成并导出视频。
- 结果：可播放的实际视频、可追踪的任务进度和供应商任务记录、会话结束后可恢复的项目。最终费用以用户的供应商账单为准。

## 第一版范围

### 统一登录与本机入口（用户新增确认）

2026-09-06 用户要求沿用 CZMIYOU 原统一登录页，登录后点击衣装产品 4：检测并尝试唤醒本地插件，成功则进入原衣装界面，未检测到则打开 GitHub 下载入口。不把进程未运行直接声称为未安装。普通用户只使用 AIGC 虚拟人像；真人活体授权不提供入口，正常素材审核与合法使用确认仍保留。新增范围需同时修改客户登录系统与插件启动/接入端；全局协议注册、线上部署和 GitHub 发布不作为本地编码的隐含执行许可。

### 登录身份修正（2026-09-06）

用户报告 LOGIN_REJECTED，并确认平时以“员工”身份登录，随后授权修复。原页面附加面板和辅助工作台都必须显式选择既有账号中心身份；保留客户、员工、代理、校企合作、管理员的服务端验证，不自动换身份试探，不绕过审批或产品 4 时间卡。错误按受控白名单区分凭据错误和身份拒绝，不外显原始上游错误。

### 最新 UI 确认（2026-09-06）

用户对简化工作台提出异议，并对“保留原来的界面和操作流程，只增加登录、自己的 Key 设置，以及 Codex／WorkBuddy 操作入口”回答“是的”。此确认替代下文单段界面作为主入口的实施假设。主页和全部原工作流页面必须复用原 HTML/CSS/JS 和业务接口；账号、Key 与网络审批只作为附加面板。0.2.0 简化界面保留为 Agent 单段任务的辅助页面，不作为默认首页。不能仅恢复页面而放行无鉴权的原 API。

- 已确认：两个宿主入口、客户版登录、产品 ID 4、时间卡、用户自带供应商 Key；不通过 CZMIYOU 代扣生成用量费，也不以中央余额充足作为生成条件。
- 已确认交付：安装包不要求客户部署后台；复用既有账号中心，客户本地运行任务管理和处理程序，直接调用其供应商账号。付费时间卡仍由既有购买/发放流程管理。
- 安全假设：复用原版人物/服装/场景替换和长视频流程，不把全部现有页面删除；用可视化预览承接人工确认。
- 数据：本地保存账号归属、项目 ID、任务 ID、素材版本、输入摘要、供应商/模型、配置版本、处理阶段、供应商任务 ID、结果引用和审批版本；不保存用户密码，不把完整凭据写进任务记录。
- 隐私：仅处理客户明确选择的素材；上传前说明供应商和存储目的地与用途。通过本地设置表单填写凭据，程序不主动把值放进聊天、工具返回、日志或分发包；本地配置文件并非能抵抗有文件访问权的 Agent 的保险箱。
- 成本：付费提交前取得与当前素材、参数和供应商配置版本绑定的人工确认，并明确由用户供应商账号扣费；估算无法确定时不得编造价格。已登录且有有效产品 4 时间卡并不等于已经批准上传或消费。
- 失败：付费提交结果不明时保留待恢复状态，不自动重复提交。取得供应商任务 ID 后只查询原任务；授权或网络故障不能删除本地任务和产物。
- 实施范围：沿用单段参考重绘作为首条闭环，旧网页其他模式保持原样，后续逐条迁移；用户已授权本地代码改造。自带 Key 不代表供应商能覆盖全部本地模型能力，不能未经验证取消深度参考等功能。
- 推荐授权策略：首版在线验证；授权到期/无法验证时阻止新受限处理和新付费提交，但不阻断已提交任务的查询、结果取回和已有文件导出。该恢复过程不得新建付费任务。

## 暂不做

- 未确认的付费调用、隐私上传、密钥使用和公开部署。
- 超出最小真实闭环的专业产品广度。
- 不把“接入 CZMIYOU”解释为把中央数据库或供应商密钥分发给客户。
- 不默认迁移所有模型到第三方云 API，也不默认取消深度参考视频。
- 不另建视频生成中转后台，不分发平台 Key、中央数据库密码或登录签名密钥。
- 不承诺本地源代码包不可破解；设备绑定、离线授权和强防复制不默认为首版范围。

## 验收标准

- 安装：分别在 Codex 和 WorkBuddy 中验证可发现、可调用；配置文件通过检查不等于真实宿主验证。
- 账户：真实账号登录成功；未登录、无有效产品 4 权限或产品停用时按既有账号中心判定拒绝新任务。覆盖叠加时间卡及未来尾卡，不能另写简化时间判断误拒有效客户；中央余额为零但授权有效时仍可使用自己的 Key。
- 隔离：受支持的界面和工具接口按账号隔离项目和任务；切换/退出账号使旧授权失效，排队任务不能借用另一账号的授权或 Key。客户对本机文件的管理员权限不是可由本地插件消除的安全边界。
- 费用：只在确认后调用客户选定的供应商，不调用 CZMIYOU 中央报价/扣费接口；同一生成任务恢复不重发付费提交，异常状态留有记录。
- 恢复：关闭并重新打开宿主后，能继续读取原任务与已完成产物，不能把提交超时误判为可重试失败。
- 审批：素材、参数、账号或供应商凭据配置版本变化使旧批准失效，禁止沿用旧确认发起新收费任务；API Key 的值不用于可外显的审批摘要。
- 视频：用户检查中间结果；最终 MP4 可探测、可解码、可播放，镜头与时长符合已确认目标。
- 配置：缺少所选能力的凭据时给出明确提示；包内只有空值 `.env.example`，不含真实 `.env`、令牌或用户数据。依赖检查说明哪些本地能力需要另行安装，缺少依赖不伪装成功。
- 发布：新架构独立审核和回归完成后才打包；分别验证真实登录/时间卡、供应商扣费与成片、Codex 和 WorkBuddy 宿主发现，不沿用旧中央网关测试作为新模式通过证明。
