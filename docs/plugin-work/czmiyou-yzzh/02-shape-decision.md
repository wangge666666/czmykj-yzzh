# 形态判断：衣装智换客户版插件

创建日期：2026-09-06

## 当前判断

最新修正：Companion 的主 UI 就是原项目 web/ 页面，不再单独设计简化首页。原 web_app 在按账号隔离的私有子进程运行；附加面板管理登录、Key 和逐次网络确认。0.2 单段工作台仅作 /agent-workbench 辅助入口，两个任务 ID 体系明确区分；0.3 增加 original_analyze / original_status 连接原长视频流程，不声称所有原操作都有 MCP 工具。

当前目标：本地 Companion Web App 为可视化主界面，薄 Skill + stdio MCP 为两个宿主的操作入口；复用既有 CZMIYOU 账号中心验权，模型任务由客户本地程序使用客户自己的 Key 直连供应商。

用户已确认客户版、ZIP 交付、保留登录/时间卡及自带 Key，并要求改造。保留原网页但不把其无鉴权接口暴露到客户版公网。下述新边界已落实于 0.2.0 本地技术预览，真实业务/宿主验收仍待完成；旧中央生成网关不是客户使用的必需服务。

共同约束：需要自然语言入口、稳定可调用工具、后台任务状态，以及真实的预览/批准交互。仅提供提示词或网页启动器不能满足已确认目标。两种宿主可以共享业务接口，安装元数据与宿主能力必须分别验证。

选定：客户本地处理与持久任务＋既有账号中心授权＋供应商 API。客户不自行部署后台，但仍需 Agent 引导安装本地依赖；安装模型和下载权重需单独说明/确认。供应商侧费用、开通权限和必要存储由客户承担，不能承诺任意 Key 都可执行所有功能。

不选纯 Skill：提示词不能代替预览、明确审批、长任务恢复和稳定工具。第一版不以内嵌 MCP UI 取代本地预览工作台，避免未验证宿主 UI 兼容性成为硬依赖；两个宿主分别验证安装和调用。

不再采用独立中央生成中转：用户已选择自带 Key，不需要平台托管模型凭据、生成任务或逐次扣费。历史 `yzzh_cloud` 技术预览暂留，不删除、不部署、不再作为新包默认依赖。

升级条件：只有用户以后明确要统一代收费、跨设备项目或更强服务端执行约束时，才重新讨论中央生成服务。当前在线验权是正常商业授权，不承诺本地代码不可被改写；设备限制与离线策略另行确认。
