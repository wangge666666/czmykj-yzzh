# 设计：衣装智换客户版插件

创建日期：2026-09-06

## 0.5.0 统一入口与自动素材传输（当前设计）

- 原 CZMIYOU 登录页 → 已授权的产品 4 → 用户点击触发固定 `czmiyou-yzzh://start`，只唤醒明确安装的本地程序；网页仅连接 127.0.0.1:7871，不扫描本机。
- 新窗口的 origin、source、随机 state 必须一致才通过 postMessage 传递登录 token；本地一次性 nonce 60 秒过期、先消耗再校验。本地重新向账号中心验权，未验证的浏览器账号字段不被信任。token 不放导航 URL、GitHub 链接、协议参数或落盘。无卡用户不能创建受限任务。
- 原衣装页不重复显示密码表单；登录后继续原步骤和附加设置。未发现时约 18 秒打开 GitHub；不能将超时等同未安装。启动器注册为显式独立动作，不默认更改系统或其他 MCP 配置。
- 默认自动素材上传为 Litterbox，申请 72 小时、持链接公开访问、无提前删除支持；用户逐次批准才上传。此明确选项替代下文历史设计的“不允许匿名中转”，不开放任意托管方或公网隧道。完整旧 TOS 配置仍可使用。
- 仅 AIGC 虚拟人像素材库审核，写实入口标记为写实虚拟人像；不提供真人活体授权，不伪造素材通过状态。

## 原界面保留适配（历史切片，以上节为准）

- 默认首页及八个工作流页面直接使用仓库 web/，原文件不改；注入独立的登录、Key、逐次网络确认面板。保留简化页面作为 /agent-workbench 辅助入口。
- 原 web_app 在按账号隔离的本地子进程执行，runs 与缓存归属账号；不读取源码根目录 .env，也不继承供应商环境变量。原 API 经回环主服务鉴权、会话版本检查后转发，内部进程另有随机凭据。
- 复用原任务流程，而不是重写生成逻辑。网络边界冻结请求正文及其摘要，在上传和云端修改/生成之前暂停等待人工批准；确认绑定账号、配置与登录会话。每次付费请求（包括旧逻辑的重试）都重新确认，结果不明保留记录并阻止继续修改。
- 只允许方舟、客户北京 TOS 和火山人物库目的地。临时公网隧道、匿名中转及浏览器代操作通道不默认为 BYOK；缺少本地模型明确提示，禁止后台自动下载大模型。
- 原页面本地拆镜和预览作为首条实测切片；完整线上生成仍需真实账号、用户素材与费用授权，不能用合成测试代替。

## 当前设计：授权与模型费用分离（0.2.0 技术预览已实现）

本节按最新需求替代下方旧预览的中央报价/上传/扣费链路。用户已授权实施；代码、配置页和新分发包按本节改造，旧预览和旧网页保留。模拟接口/本地视频验证不能替代真实账号、供应商和用户验收。

实现补充：首个适配器固定火山方舟/北京 TOS，模型 ID 由客户填写并自行开通。配置按账号保存，写入/清除绑定账号和非秘密会话版本，旧标签页返回 409；普通刷新不回显 Key。生成计划明确无可靠估价及客户存储/流量费用。上传对象不自动删除，用户需配置生命周期；上传记录持久化，读取签名不进入公开任务或 SQLite。

### 客户看到的流程

1. 把 ZIP 交给 Agent，检查宿主与本地依赖；在安装确认后启动仅本机可访问的工作台。
2. 首屏提示登录 CZMIYOU；用户在表单填写账号密码，显示产品 4 授权有效期，不在聊天或 MCP 参数传递密码。
3. 在“模型设置”填写自己的供应商凭据。首版只提供明确支持的供应商适配器；模板只含空值，不宣称任意 API Key 通用。只有真实验证接口无费用风险时才提供对应连接检查，不拿付费生成冒充检查。
4. 导入素材、本地处理、检查中间预览；缺少依赖说明安装范围，不能假装完成打码或深度推理。
5. 生成前展示上传目的地、素材、模型、时长等参数、费用承担方和可获得的估算；用户批准后再验证产品授权，由本地程序直接提交供应商。
6. 显示持久进度，保存供应商任务 ID；查询、下载、预览和导出。到期后保留历史结果取回能力，但不创建新的付费任务。

### 授权契约与现有代码依据

- 0.3.1：两个登录表单增加必选 role，HTTP → Runtime → AccountClient 原样转发允许的 customer/staff/agent/partner/admin。缺省 role 的旧调用继续按 customer，显式空值或非法身份拒绝且不联网。身份仅为请求，不是授予权限；服务端审批、token 二次校验及产品 4 门禁不变。对已知账号/密码或身份拒绝映射稳定错误码，401/403 的异常成功包也不能登录，未知文本不回显；不自动换角色重试。

- 既有账号中心源码：`CZMIYOU_kehudengru/src/app/api/auth/login/route.ts` 的 `POST /api/auth/login` 接受客户登录，返回 token；`src/app/api/auth/verify-token/route.ts` 的 `POST /api/auth/verify-token` 接受 JSON `{token}`，服务端验签并查询有效订阅。
- 本地授权适配器仅向固定可信 HTTPS 账号中心发送令牌，要求 `valid === true` 且服务端筛选后的 subscriptions 包含 `productId === 4`。登录成功本身不等于产品授权成功，不以 balance 判定是否可以用自己的 Key。
- 有效期及叠加时间卡覆盖由现有服务端判断。当前源码兼容“旧卡 superseded、active 尾卡起点在未来”的连续覆盖；客户端不得用简单起止时间判断替代它。
- 首版建议在线验证：登录时取得显示信息，每次执行新受限处理/付费提交前重新验权。UI 与 MCP 共用运行时门禁，而非只隐藏按钮。网络错误显示“暂无法验证授权”，不伪报“已到期”，不继续新任务。
- 验签密钥和数据库连接仍只在账号中心。插件不本地复刻 HMAC 验签，不接中央 MySQL，不向账号中心发送供应商 Key 或素材。账号切换/退出清空旧授权；排队任务在真正执行前重新验证所属账号及配置版本。
- 本地代码已能复用此接口，不代表线上账号中心是同一版本。真实账号、产品 4 与叠加卡联调是发布门禁；如果需要兼容接口，只改既有账号中心，不要求新建视频后台。
- 上轮只读审查发现账号中心本地源码中存在固定历史管理员凭据的兼容分支。商业发布前需另行审查和移除该风险并保护正常管理员入口；未证明线上存在同样代码，本轮不调用、不修改、不记录任何真实凭据值。

### 本地任务、凭据与审批边界

- 保留本地项目、SQLite 任务恢复、可视化审批、薄 MCP。新增授权适配器与本地供应商适配器；绕过旧中央 quote/submit/charge 链路，模板中不再要求独立生成网关地址。
- `.env` 可以作为客户私有配置文件；首版通过本地表单引导配置，分发包只提供 `.env.example` 空值模板。密码不落盘，登录 token 默认只在内存；重启后重新登录仍可关联持久任务。必要的凭据持久化需限制文件权限，可后续接系统钥匙串。
- 程序不将 Key、令牌、签名下载 URL 放入 MCP 返回、日志或错误文本；只返回“已配置/缺失”。`.env` 是本地明文配置，不保证能抵抗有本机文件权限的 Agent；不把不暴露在正常工具输出误称为绝对不可访问。
- 任务存储账号 ID、供应商标识、非秘密配置版本、输入哈希、参数、审批版本、供应商任务 ID 和本地产物路径。Key 不复制进 SQLite 或审批摘要；每次凭据更新递增非秘密配置版本，使旧批准失效。
- 上传前明确供应商及必要的对象存储。若供应商必须公网素材地址，需适配客户自己的存储/上传能力并说明凭据、费用和清理策略；不能私自回退到平台 TOS 或承诺单一模型 Key 已覆盖此条件。
- 单段生成闭环最先迁移；现有深度、打码等本地模块不因 BYOK 自动删除，也不自动替换为未验证的外部模型。原大网页暂不受本轮影响。
- 提交前先持久化本地任务和批准版本；付费 POST 返回不明进入 `submit_uncertain`，有供应商 ID 只查询，无 ID 按官方能力恢复或转人工核对，不自动重提。供应商已受理后授权到期仍允许只读查询与取回，不能靠恢复入口新建生成。
- 本地 Host/Origin、随机会话凭据、CSRF、登记产物访问和账号隔离保留；本地源代码可被客户改写，属于商业授权软约束，不宣称不可破解或强 DRM。
- 桌面工作台为首版；不承诺手机远程控制或移动端本地视频处理。Codex/WorkBuddy 安装入口分别核验，打包成功不等于宿主发现成功。

### 状态与可观察验收

- 首屏空态：未登录 / 待配置 / 无项目；验权中与配置检查中明确 loading。拒绝批准回到可编辑计划，批准后显示实际执行进度。
- 账户异常区分登录过期、无产品权限、授权服务暂不可达；旧数据保留。有效产品 4＋中央余额为零能进入用户自带 Key 提交；无权限调用界面或 MCP 均被拒绝。
- 输入、参数、账号或配置版本变化使旧批准失效；并发切号、排队执行和重启后不得错误借用权限或凭据。
- 正常提交后完成 MP4 探测/解码/人工预览；失败和不明提交可追踪，不把未生成状态展示为 completed；同任务恢复不再次付费提交。
- 网络、模拟供应商和伪时钟测试覆盖授权失效、叠加卡、到期后的取回，以及“不调用中央扣费”；真实线上账号和用户自有供应商验收单独授权，不用模拟通过代替。
- 打包检查允许空模板而拒绝真实 `.env`、云端平台凭据、私有素材和运行数据库；双宿主实际发现、合成视频闭环及真实视频验收分别记录。下方旧预览的 46 项测试不计作以上新目标通过。

## 历史运行契约：中央代收费技术预览（2026-09-06）

以下保留已实现架构的追溯信息，不再是新客户包的目标。

- `yzzh_local`：凭据外置、仅回环监听的工作台；持久项目和异步预处理，stdio MCP 是薄客户端，关闭宿主不杀死视频任务。
- `yzzh_cloud`：独立 Flask 服务，仅载入服务器配置；CZMIYOU HMAC 验签、产品 4 / 有效时间卡、中央报价、任务幂等与记账。不得导入原网页或本地模型。
- 第一条切片：本地导入、分镜、打码、深度；选取一段参考视频和参考图片，编辑提示词；报价后在工作台检查并确认上传/费用；提交云任务；查询恢复；账单成功后下载预览和导出。
- 初始状态为空项目；预处理为 running/ready/failed；中断为 interrupted；云提交前写 submitting，响应不明为 submit_uncertain；有供应商 ID 则只查询；账单异常为 reconciliation_required，不提交第二个付费任务。
- 审批绑定输入文件 SHA256、参数和中央价格快照，生成计划后修改文件使审批失效。界面操作与 MCP 操作共用运行时约束。
- 远端不接受任意 provider URL、用户 ID、用量、价格或供应商任务 ID。认证身份来自中央验签，报价和幂等任务归属来自服务器数据库。
- 本地工作台检查 Host、Origin 和随机会话凭据，禁止跨站请求与任意文件下载；文件服务仅针对已登记产物。账号凭据不作为 MCP 参数或工具返回值。
- 密码/令牌仅在用户交互表单中输入，不进入聊天；最终登录体验依赖既有账号中心接口，真实账户联调为单独门禁。
- 客户包采用明确文件白名单，不包含服务端账号代码、.env、测试素材、运行数据或模型；本地依赖不包含 Demucs/Torch/CUDA，模型安装单独显式触发。
- 首版支持桌面回环工作台。手机只考虑页面阅读，不承诺本地处理或远程控制。双宿主分别验收，协议测试不能替代宿主发现。
- 全局安装、公开域名部署、真实账户和扣费、用户私有素材上传均未授权。本轮使用临时目录与合成视频验证。
